# 椅子坐下动作重做

本次把原先统一平滑插值的坐下段，改为约 1.8 秒的五阶段动作：准备前倾、臀部后移、受控下降、接触缓冲、收手坐稳。仅用于 `?resident=tripo` 的生活舱办公椅。

## 动作与接入

| 片段 | 时长 | 内容 |
| --- | --- | --- |
| `ChairSitDown` | 1.8 秒 | 前倾准备 → 后移 → 下降 → 轻微沉降回弹 → 双手收至裙面 |
| `ChairSeatedIdle` | 4 秒循环 | 轻微躯干呼吸；脚部与坐姿支撑持续保持 |
| `ChairStandUp` | 1.7 秒 | 双手离开腿面、前倾、抬臀伸腿，衔接原站姿与 Walk |

- 新动画保存在 `public/models/resident/luna-chair-motion.glb`，包含骨骼旋转、Hips 位移与既有 49 个 morph 的动画通道。60 Hz 烘焙，运行时由原角色的 AnimationMixer 采样。
- Sidecar 只加载动画；用于绑定 morph 通道的零面积占位网格不会加入场景。没有替换角色皮肤、骨骼或材质。
- 双脚使用原站姿锚点及原骨长，腿部保持各自屈膝平面。手部跟随当前大腿与裙面上包络，左右收手时间错开约 0.045 秒。
- 移除坐下期间的旧固定手部 IK，避免覆盖新动画。坐下、坐稳、起身由独立片段全权重播放，Walk 权重为零；返回移动时继续使用原 Walk。
- 后裙、侧裙和后发在接触阶段逐渐缩小二次运动幅度，前侧自由区域保留惯性。继续使用既有椅面/靠背接触修正，并不引入完整布料模拟。
- `ImportedPose` 保持先恢复导入姿势再施加程序修正的顺序，防止不变关键帧上的修正累积。

## 复现

1. 运行 `node scripts/build-chair-motion.mjs` 重建动画 GLB 与 `authoring.json`。同一输入重复构建的字节一致。
2. 运行 `npm run typecheck`、`npm run build`，构建完成后再运行 `node scripts/test.mjs`（游戏集成测试读取构建产物）。
3. 使用已安装的 Playwright 与 Chrome，按需设置 `PW_MODULE`、`BROWSER_PATH`；运行 `node scripts/check-chair-seating.mjs` 检查完整交互。通过 `CHAIR_PORT` 和 `CHAIR_OUTPUT` 设置独立端口与输出目录。
4. 把原分支 `f3803c96` 的工作区路径设为 `CHAIR_BASELINE`，运行 `node scripts/review-chair-motion.mjs`。默认原工作区是 `../chair-stage2.local`，输出 `chair-motion-review.local/`，端口为 8976/8977；`--current-only` 可只录新版。
5. 在已有 ffmpeg 的环境运行 `node scripts/package-chair-motion-review.mjs`，生成并排正常/半速录像与本验收页。若第 4 步设置 `CHAIR_OUTPUT`，此步保留相同值；`CHAIR_FLOW_OUTPUT` 可指向第 3 步的输出以更新交互摘要（默认 `chair-review.local`）。截图裁切和视频编码不改变实际动画。

## 测量修正与限制

分析时发现旧离线加载器的 `select()` 会恢复场景根节点缩放。现在所有新增采样与两处旧接触测试都在 `select()` 后应用实际 1.45 倍缩放，旧分析中基于 1 倍缩放的位移/穿入数量不再作为依据。旧坐下实际髋部下降约 0.3271、后移约 0.2929；新下降约 0.2870、后移约 0.2920。椅子始终保持原尺寸；新动作通过髋部目标与原腿长适配支撑。

原模型裙褶仍存在硬折；表面接触修正并非布料自碰撞，后发仍用近似靠背约束。实体手机、Safari 和长期性能未验证。脚蹬地推进、轮组运动与转向不在本次范围。

此分支从最新 `main` 建立，并合入尚未合并的 PR #33（其包含 PR #27 角色依赖）。本次新增动作的独立增量从 `f3803c96` 起；交由队长审查与合并。
