# 蓝发少女角色

以用户确认的 `references/board.png` 为唯一外观依据。正面全身确定比例，面部特写确定五官，侧面和背面用于补全体积。参考板附带的兔子不属于本次人体重建范围。

## 造型基准

目标身高 1.43 m，约 5.7 头身；头顶、下巴、肩、腰、裙摆、膝分别约为 1.43、1.18、1.11、0.94、0.53、0.40 m。正交正面检查窄肩、纤细四肢、大头和柔和下颌，不使用写实成人比例。

眼睛为蓝紫色，眼位偏低，上眼睑清楚，鼻口小而克制。浅蓝长发拆为头顶、分叉刘海、脸侧长束和背部波浪束，发尾落在腰臀附近。白裙使用胸前罩片、细肩带、独立腰边、主裙和两层裙边；正面中央为粉色立体蝴蝶结及双飘带。

## 交付约定

`character.blend` 保留可编辑对象与骨骼，`character.glb` 为运行模型；`renders/` 为实际模型渲染，`textures/` 为导出用纹理。工程使用项目相对路径。头发和裙摆骨骼为运行时二级动画接口，Blender 布料模拟不作为 WebGL 交付。

模型通过外观与动作检查后接入 PocketWorld；旧资产保留，现有运行时重新生成骨架的逻辑需要针对原生蒙皮模型适配。审查进度及未验证项记录在本任务 PR。
