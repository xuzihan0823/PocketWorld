# 冬日分层雪景

四个原生 SVG 图层均为 1600×900、16:9，允许独立编辑和横向平铺，不包含人物、文字、按钮或水印。

| 图层 | 内容 | 相机速度 |
| --- | --- | --- |
| sky.svg | 冰雪蓝天空、奶油白云朵、柔和太阳 | 0.018 |
| mountains.svg | 朦胧远山、蓝灰山峰与哑光雪冠 | 0.075 |
| woodland.svg | 连续雪坡、覆雪松林和零星木屋 | 0.25 |
| decor.svg | 底部小石块、低矮积雪灌木 | 0.6 |

panorama.svg 是无人物、无界面的叠层预览。游戏在 assets.ts 中生成三条雪道的配色变体并缓存为十二张800×450画布，像素缓冲约16.5MiB，数量固定。renderer.ts 将源图等比覆盖现有800×600卡带，再绘制实际地面、障碍和角色；不把装饰图作为碰撞依据。

所有图层的左右边缘高度与填色保持一致，装饰物不穿过边界。近景装饰位于画面底部，主雪道上方没有大型前景树木遮挡。三视图、源网格与全景图不进入网页运行包。
