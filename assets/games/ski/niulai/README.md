# 黄色牛来伙伴素材

依据用户提供的「牛来原皮」参考图重新绘制黄色牛来，保留橙黄色身体、外张耳朵、宽鼻吻、细眉眼和浅色蹄子，并制作两种伙伴动作。

| 动作 | 独立动画 | Canvas 序列图 | 伙伴用途 |
| --- | --- | --- | --- |
| 贴地滑行 | niulai-slide.svg | niulai-slide-sheet.svg | 持续加速与贴地滑行，吸收一次撞击后离开 |
| 冲撞奔跑 | niulai-charge.svg | niulai-charge-sheet.svg | 承担雪怪的骑乘与撞开普通圆石能力 |

两种伙伴共用黄色牛来身份，切换时采用对应姿态，已接入游戏的骑乘位置和碰撞判定。两种形态均不设持续时间或距离上限；遭受撞击保护消耗、摔倒或被豆包抓住时结束骑乘。

## 播放方式

独立动画使用 SVG SMIL，直接在浏览器打开，或通过 HTML 的 object 元素加载即可预览。眨眼周期为 3.2 秒，滑行循环为 1 秒，冲撞循环为 0.64 秒。

Canvas 2D 接入时使用两个 sheet 文件和 animations.json。每张序列图横排 8 帧，每帧为 320 × 360，整张为 2560 × 360。加载一次后，按游戏累计运行时间选帧并通过 drawImage 的源矩形裁切绘制。滑行为 8 FPS，冲撞为 12.5 FPS。暂停时冻结累计运行时间，恢复后继续，避免脱离游戏时钟的独立循环。

animations.json 的 rideAnchors 为八帧分别标定背部接触点，来自各帧身体旋转、缩放与起伏变换。骑乘绘制以接触点为锚，按原有骑乘高度归一缩放，让主角脚底始终贴合；拾取场景仍使用groundAnchor。两者先组合再应用完整旋转，空中固定牛来的中立帧，落地恢复跑动。

帧索引可按 floor(elapsedSeconds × fps) % frameCount 计算。源矩形为 frameIndex × 320、0、320、360。groundAnchor 为每帧局部坐标中的雪面参考点 160、340，实际骑乘锚点与判定盒由游戏接入时配置。

独立动画采用 SMIL 的姿态变化与眨眼时钟，序列图采用睁眼表情和八帧姿态变化，方便游戏独立控制表情节奏。

## 参考与绘制

本版按用户提供的参考图重新设计贝塞尔轮廓，使用渐变表现额头、鼻吻、肚子和四肢的体积。头部、眼睛、躯干、手臂与腿部分层定义，滑行与冲撞分别组合姿态。

冲撞采用站立前倾、交替迈步、手臂摆动与身体起伏。滑行采用身体横卧、抬头、伸臂与蹄部摆动。独立动画另有眨眼。

本版采用适合游戏小尺寸显示的简化矢量风格。参考图中的立体光照、材质与毛发细节经过概括。

## 已验证范围

Chrome 中独立 SVG 在不同时间点的截图有变化。两张序列图均可由 Canvas 2D 解码绘制，各自 8 帧均有图像且像素结果互异。已检查 XML 引用完整性、透明背景、角色边界和文件体积。

游戏已接入骑乘、冲撞、静音与暂停，自动检查范围及尚待人工验收的反复进出、音效听感等事项见模块进度文档。
