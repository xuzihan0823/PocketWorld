# 豆包追赶群素材

本目录保存用户指定 Petdex doubao-4 页面提供的原始素材包解压内容。形象为黑色上衣、米白长裤和棕色短发的 3D 玩具风格豆包。来源与原始下载地址见下方链接。

- https://petdex.dev/pets/doubao-4
- https://assets.petdex.dev/pets/doubao-ba163d674992/zip.zip

pet.json 与 spritesheet.webp 保留原始字节，文件间相对路径可直接对应。

## 动作图格式

spritesheet.webp 为带透明通道的 1536 × 1872 WebP，按 8 列、9 行排列，每格 192 × 208。向右奔跑位于第 2 行，向左奔跑位于第 3 行，均为 8 帧。以零起始编号表示时，行索引分别为 1 和 2。

用于向右滑雪时，后方追赶群读取向右奔跑动作。各豆包可错开帧相位，并以人物身体范围建立碰撞盒。Canvas 接入时先解码缓存动作图，由游戏时钟选帧。

文件大小为 944,382 字节，约 922 KiB。已与原始 ZIP 及此前下载的精灵图逐字节核对。
