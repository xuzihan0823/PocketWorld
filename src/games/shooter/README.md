# shooter 卡带：团团魔法录

以手绘像素魔法风呈现的轻量生存肉鸽，沿用 shooter 标识和 GameCartridgeProps。场景固定按 640 × 480 高清绘制；逻辑布局仍为 800 × 600，战斗角色、兵装、魔物、地形和特效均由代码绘制。角色选择使用宣传海报与五职业立绘图集，未引入游戏引擎、模型或音频文件依赖。

## 整站运行与接入

房间通过实体卡带加载游戏。读取完成后，卡带内直接显示角色和开局武器选择。选角页的「离开电脑」调用宿主退出回调，房间侧的装卸、显示和退出流程见 [SPEC.md 第 3 节](../../../SPEC.md#3-卡带小游戏集成契约)。

安装根 package.json 声明的依赖后执行：

```powershell
npm run dev
npm run build
```

访问开发服务器的 `/?dev=shooter` 直接打开独立卡带沙盒，不需要加载 Three.js 或轨道房间。沙盒提供静音、外层停用与装卸操作用于联调。整站根入口仍进入 3D 轨道房间。

## 界面与场景

选角背景使用五职业迎战怪群的海报，五幅角色立绘下方显示当前职业天赋和三种开局兵装。「出发冒险」位于右下，底部可打开手记、查看最高分或离开。独立调试页中，按 Esc 从手记返回选角。房间和独立页共用最高分，写入时重新比较其他标签页已保存的成绩。固定 4:3 排版适配窄屏。海报及像素道具图标来源见[素材说明](../../../assets/games/shooter/README.md)。

五套局内像素角色按海报重画：游侠宽檐帽与银发、机巧师青色双马尾与铜护目镜、炼金师红发与红披风、术士紫色星帽、魔女绿花帽与斗篷。角色转向时翻转立绘，冲刺残影与受击轮廓沿用各自的造型。

战斗场景采用青绿月夜地面、紫色遗迹与树冠、粉紫蘑菇和高饱和魔物，加入发光拱门、符文与萤光粒子；角色发色与立绘对应。魔物受伤时整个身体短暂纯白闪烁约 0.12 秒并出现命中火花，随后恢复原色。角色受伤时短暂闪白、粉红受击轮廓和渐隐屏边提示，保留原有无敌时间与轻微震屏，不改变伤害和碰撞。

战斗状态沿画面边缘布局。左上为职业头像、等级与灰粉生命条，顶部中央显示倒计时和波次，桌面同时显示得分。右上为小地图与暂停，左下为武器，右下为冲刺，底边为经验条。HUD、暂停与结算采用低饱和的半透明月夜配色。小屏武器槽保留像素图标和编号，完整名称可从切枪提示或辅助标签读取。

小地图以玩家为中心显示附近敌人，浅金菱形代表自己，灰粉圆点代表普通敌人，带外环的亮紫点代表首领。敌人死亡或离开显示范围后移除标记。小地图约每 100 毫秒随 HUD 更新，暂停与升级时停在当时的画面。

## 实体键盘同步

电脑下方的键盘支持真实键盘联动：按住时对应键帽下压并变暖色，松开回弹。支持多键同时按下，WASD 与方向键有浅绿底色，空格、修饰键、数字和常用功能键均有对应位置。该反馈只观察捕获阶段的按键事件，不拦截游戏控制；失焦、隐藏和离开页面自动清空。

实现位于 scene/orbital/media/ReactiveKeyboard.tsx 与 keyboard-input.ts；77 个键帽使用实例化绘制，标识来自一张本地生成图集，没有新增网络资源或依赖。

## 职业与操作

- 开局先选职业：魔弹游侠、符文机巧师、爆破炼金师、星辉术士、疾风魔女，各有外观与职业天赋。
- WASD / 方向键移动；场地内按住鼠标或触屏拖动也可移动。自动攻击最近敌人，靠近经验晶体升级。
- 开局选择职业后，本局仅能使用该职业的三种武器；战斗中没有切换职业或跨职业兵装的入口。
- 空格冲刺；Q / E 前后切换本职业武器，数字 1～3 直选，R 兼容下一把。可点击底角的三枚武器按钮，点击后可直接按空格冲刺。三把武器共享秘术与装填冷却。切枪在武器槽上方短暂显示名称，约 2.2 秒后淡出。
- 高清场景固定为 640 × 480，支持半像素细节。逻辑空间为 800 × 600，输出 Canvas 按设备像素比绘制，最高两倍。
- 「月下觉醒」以星形胶囊标题与半透明暗幕覆盖暂停的战场，保留上方 HUD 与周围场景，卡面上方以低饱和斜纹衬托对应秘术的像素道具，下方用半透明淡紫底展示名称、效果、等级与快捷键。底部一行显示联动进度，能补全或已激活时直接提示联动效果。升级卡池优先提供两张职业秘术和一张辅助或适配元素。学会联动的一半后，下一次升级优先出现搭档，能补全联动的卡片有金色描边和明确提示。数字 1～3 或点击选卡，R 或按钮重抽，每局两次，满级项目移出卡池。
- 战斗循环曲《月下嗒嗒舞》以跳音、铃声和短促低音构成。15 种武器分别合成发射声，三连铳按实际点射间隔响三次，爆炸有单独低频冲击。暂停、升级、失焦和静音时停声，恢复后从后续节拍继续。选角或暂停页的游戏声音开关同时控制背景音乐与音效。
- 战斗中按暂停按钮、P 或 Esc 暂停，用「继续冒险」或 P 恢复。失焦、隐藏或外层停用会自动暂停；暂停和升级时停止模拟与动画循环。房间显示控制按宿主流程处理。
- 生存十分钟获胜，最后一分钟出现首领；每 45 秒怪潮，90 秒后开放带预警的地面法术。

升级卡牌仍展示效果与等级；战斗中的状态和操作集中到边缘，构筑详情放在暂停页，适配房间电脑内的显示尺寸。

每个职业配三种武器流派，共 15 种兵装；同职业三种武器共用四张专属秘术，共 20 张。五职业各有一组双卡联动，集齐后同职业的三种兵装共享，并在触发时显示联动名称。具体效果和数值见[平衡说明](survival/平衡说明.md)。

| 职业 | 三种兵装流派 |
| --- | --- |
| 魔弹游侠 | 暮色手枪（精准）／荆棘霰枪（散弹）／贯星长铳（贯穿） |
| 符文机巧师 | 符文机关枪（连续）／脉冲三连铳（点射）／棱镜电磁炮（电束） |
| 爆破炼金师 | 炼金火箭炮（直击）／陨星迫击炮（落点）／符印地雷匣（布阵） |
| 星辉术士 | 星辉法杖（追踪）／霜扇短杖（冰霜）／月轮魔典（回旋） |
| 疾风魔女 | 魔女扫帚（群扫）／风骑长枪（突刺）／旋刃飞帚（投掷） |

炼金师的「星火集束」随兵装改变。火箭炮在爆点前方追加短锥贯穿爆风，迫击炮仍散出三枚小火箭，地雷匣向四周布置三枚低伤害、短范围的小地雷。选卡时显示当前兵装的效果。

## 文件与验证

- `survival/index.tsx` / `style.css`：状态、输入、卡牌与像素魔法界面。
- `survival/engine.ts`：独立模拟、职业、秘术、卡池重抽、命中停顿和有界对象。
- `survival/arsenal.ts`：15 种武器的攻击方式、流派、数值和默认装配。
- `survival/professions.ts`：五职业、20 张专属卡与各职业适配元素。
- `survival/UpgradeIcon.tsx`：将 35 项升级映射到像素图集。
- `survival/render.test.mjs`：验证怪物身体逐像素闪白与恢复原色、角色受伤视觉反馈及渲染不改动对局。
- `survival/pixel-art.ts` / `WeaponGlyph.tsx` / `render.ts`：共用像素图案与场景绘制。
- `audio.ts`：Web Audio 分层合成背景音乐与各兵装音效，跟随游戏生命周期。
- `dev.tsx` / `dev.css`：正式 Vite 独立沙盒。
- `integration.test.mjs`：生产产物依赖图检查，验证主入口、独立调试页和动态卡带插槽。
- `survival/engine.test.mjs`：模拟测试，包括普通十分钟模拟、五职业分别锁定后的满级十分钟压力模拟及专属效果。
- `survival/combat-regressions.test.mjs` / `collision.test.mjs`：战斗与首次接触几何回归，包括近战出手、弹组瞄准、三兵装的集束效果与地雷过期。
- `audio.test.mjs`：覆盖音乐停续与重开、武器多段音效取消、静音恢复、停用与快速状态切换，使用异步 AudioContext 替身。
- `survival/input.test.mjs`：组件事件回归覆盖多指摇杆、停用清理、点击切枪后按空格冲刺，以及独立页面用 Esc 关闭冒险手记。

在项目根目录使用 Node.js 24 运行 `npm test`，统一入口自动构建生产产物、生成生存引擎测试包并执行全部回归。
