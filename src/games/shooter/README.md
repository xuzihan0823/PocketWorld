# shooter 卡带：团团魔法录

以手绘像素魔法风重做的轻量生存肉鸽，沿用 shooter 标识和 GameCartridgeProps。默认按 640 × 480 绘制，保留 320 × 240 节能档；逻辑布局仍为 800 × 600，角色、兵装、魔物、地形、特效都由代码绘制，没有新增图片、模型、音频文件或游戏引擎依赖。

## 整站运行与接入

最新轨道房间使用实体卡带交互：按 C 靠近电脑，按住电脑左侧紫色卡带，拖到右侧卡槽附近后松手，插入后按需加载本目录 index.tsx。单击只聚焦电脑；在其他位置松手自动归位，不启动游戏。游戏首页退出会拔出卡带，内部返回首页不拔卡。

安装根 package.json 声明的依赖后执行：

```powershell
npm run dev
npm run build
```

访问开发服务器的 `/?dev=shooter` 直接打开独立卡带沙盒，不需要加载 Three.js 或轨道房间。沙盒提供静音、外层停用与装卸操作用于联调。整站根入口仍进入 3D 轨道房间。

## 终端文字清晰度

电脑聚焦后由 scene/orbital/media/ComputerScreen.tsx 将实体屏幕四角投影成整像素的 4:3 二维区域。游戏 DOM 以区域实际宽高直接布局，移除原来的 scale(.46) 和 CSS 透视缩放链；像素场景仍由独立 Canvas 绘制。转场或失焦时隐藏同一屏幕并暂停，不切换渲染分支重新挂载游戏。

近景镜头同时容纳卡带和卡槽，并随视口宽高比调整。卡带拖动限制在显示器前方和桌面上方；插入、拔出、归位均沿避开机身的分段路径运动。卡带运动期间隐藏 DOM 屏幕覆盖层，避免遮住屏幕前方的实体卡带。

界面使用系统中文字体，主按钮、关键说明、武器名设置最小字号；首页保留一句目标说明、三组操作提示，将成绩、手记与退出移到底部。职业卡使用短名称，完整名称保留在辅助标签和提示中。小屏模态框可滚动查看内容。

## 实体键盘同步

电脑下方的键盘支持真实键盘联动：按住时对应键帽下压并变暖色，松开回弹。支持多键同时按下，WASD 与方向键有浅绿底色，空格、修饰键、数字和常用功能键均有对应位置。该反馈只观察捕获阶段的按键事件，不拦截游戏控制；失焦、隐藏和离开页面自动清空。

实现位于 scene/orbital/media/ReactiveKeyboard.tsx 与 keyboard-input.ts；77 个键帽使用实例化绘制，标识来自一张本地生成图集，没有新增网络资源或依赖。

## 职业与操作

- 开局先选职业：魔弹游侠、符文机巧师、爆破炼金师、星辉术士、疾风魔女，各有外观与职业天赋。
- WASD / 方向键移动；场地内按住鼠标或触屏拖动也可移动。自动攻击最近敌人，靠近经验晶体升级。
- 开局选择职业后，本局仅能使用该职业的三种武器；战斗中没有切换职业或跨职业兵装的入口。
- 空格冲刺；Q / E 前后切换本职业武器，数字 1～3 直选，R 兼容下一把。可点击三枚武器按钮，三把武器共享秘术与装填冷却。切枪显示大字号武器名称，约 2.2 秒后淡出。
- 默认高清场景 640 × 480（原为 320 × 240），支持半像素细节；右上角可切经典节能档。逻辑空间仍为 800 × 600，Canvas 按设备像素比绘制，最高两倍。切画质不重开局。
- 升级卡池优先提供两张当前武器专属秘术和一张辅助/适配元素；数字 1～3 选卡。R 或按钮重抽，每局两次；满级项目移出卡池。
- P / Esc 暂停，失焦、隐藏或外层停用时自动暂停。暂停/升级不执行模拟和动画循环。
- 生存十分钟获胜，最后一分钟出现首领；每 45 秒怪潮，90 秒后开放带预警的地面法术。

界面删除升级页规则小字、英文眉题、重复职业武器标签和空附魔提示。卡牌效果、武器名称与关键状态放大，适配房间电脑内的显示尺寸。

每个职业配三种武器流派，共 15 种兵装；同职业三种武器共用四张专属秘术，共 20 张。机制、平衡和验证限制见 survival/平衡说明.md 与本目录进度文档。

## 文件与验证

- `survival/index.tsx` / `style.css`：状态、输入、卡牌与像素魔法界面。
- `survival/engine.ts`：独立模拟、职业、秘术、卡池重抽、命中停顿和有界对象。
- `survival/arsenal.ts`：15 种武器的攻击方式、流派、数值和默认装配。
- `survival/professions.ts`：五职业、20 张专属卡与各职业适配元素。
- `survival/pixel-art.ts` / `WeaponGlyph.tsx` / `render.ts`：共用像素图案与场景绘制。
- `audio.ts`：受控 Web Audio 发射、命中、暴击、拾取、冲刺和切换音效。
- `dev.tsx` / `dev.css`：正式 Vite 独立沙盒。
- `../../scene/orbital/media/screen-layout.test.mjs`：7 项屏幕投影与放大布局测试，覆盖透视内接、窗口裁剪、非法投影及四种视口。
- `../../scene/orbital/media/media-exit.test.mjs`：13 项电脑退出与展示状态测试，覆盖收起保留、窄屏自动放大、失焦、隐藏和拔卡。
- `integration.test.mjs`：生产产物依赖图检查，验证主入口、独立调试页和动态卡带插槽。
- `survival/engine.test.mjs`：33 项模拟测试，含普通十分钟模拟、五职业分别锁定后的满级十分钟压力模拟及专属效果。
- `survival/combat-regressions.test.mjs` / `collision.test.mjs`：34 项战斗回归与 2 项首次接触几何测试，新增近战加成范围出手和星灵契约弹组瞄准检查。
- `audio.test.mjs`：3 项音频生命周期测试，覆盖静音恢复、停用/激活和快速状态切换，使用异步 AudioContext 替身。
- `survival/input.test.mjs`：4 项组件事件回归，覆盖其他手指结束不打断摇杆、松开摇杆保留键盘输入，以及外层停用清理；使用 hooks 与指针捕获替身。

在项目根目录使用 Node.js 24 运行 `npm test`，统一入口自动构建生产产物、生成生存引擎测试包并执行全部回归。

房间中宽度不超过 720px 或高度不超过 480px 时，装入卡带自动放大到可用视口中的 4:3 区域。桌面提供「放大游戏」；「回到电脑」保留并暂停本局，重新放大后点击继续。只有「拔出卡带」结束装载。窄屏菜单可纵向滚动，职业每局固定，三种兵装与秘术随展示模式保持。
