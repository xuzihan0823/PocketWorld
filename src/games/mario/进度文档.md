# 奶娃滑雪大冒险模块进度

保留 `mario` 卡带标识、`src/games/mario/index.tsx` 默认导出 `MarioGame`、`GameCartridgeProps`、`800 × 600` 逻辑画布与 `pocketworld:mario:highscore` 存档键。素材统一位于 `assets/games/ski/`。

## 当前已实现

- **核心玩法与雪道**：初晴雪谷、暮色松林、极夜冰原三条连续无雪洞雪道；自动滑行、`W`/空格起跳与按住后空翻、松手自动辅助摆正、`A/D` 空中微调、`S` 收身/快速下落、摔倒连续轻按起身、`Esc` 暂停。
- **骑乘与追赶机制**：8 名豆包从后方以圆组与路径扫掠追赶；牛来提供贴地滑行（吸收一次撞击）和冲撞（撞碎圆石）两种无限骑乘形态，骑乘时主角脚底锁定牛来背部锚点并同步翻滚。
- **判定、反馈与界面**：头部/躯干/雪板二维碰撞体积判定；空中每完成一整圈即时小加速（+45 px/s 持续 0.9s，上限 470）与技巧分倍率（最高 ×3）；覆盖雪木牌 UI、4 层 16:9 循环 SVG 雪景（支持 `reducedMotion`）、原版笑声前三秒与牛来/合成音效，触屏设备自动显示半透明双键。
- **入口与集成**：房间电脑拖入橙色卡带按需加载，或通过 `?game=ski` / `?dev=mario` 直达独立沙盒。
