# 潮汐小馆 · `mario` 当前进度

本批次 `fix/storage-review` 修复多标签页覆盖经营存档。旧页面检测到存档变化时暂停，玩家可以重新载入最新鱼篓和经营进度。

## 当前状态

《潮汐小馆》接入原 `mario` 卡位，开放一个黄昏海湾、12 种鱼、16 道菜和 3 档可切换鱼竿。玩法数值见 [README](README.md)，像素场景与交互见 [DESIGN](DESIGN.md)。

- 船上自动抛竿和收线。可轻敲加速，稀有鱼需要限时搏鱼。鱼按品种生成重量，重个体收线更久。虾肉饵缩短等口，鲜鱼块更容易吸引同种鱼中的重个体。
- 船与码头之间有双向航行镜头。两家店铺可点击场景物件，渔具店购买与换竿，大排档查看图文配方、批量制作和追踪熟客订单。岸上暂停钓鱼，制作队列继续结算。
- 每次上鱼展示渔获卡。钓鱼生涯记最大渔获及各鱼种的捕获次数，支持方向键滚动，关闭渔获卡会恢复船上焦点。
- 界面使用像素计数和状态图标、任务指南与点单簿。鱼饵面板有固定返回按钮。场景音乐与音效通过 Web Audio 合成，服从宿主静音并随停用或卸载释放。
- `?dev=mario` 打开独立调试页，旧 `?game=ski` 在房间内选择该卡带。存档由 `save:v1` 迁移到 `save:v2`；旧滑雪最高分继续保存在原键。集成合同见 [SPEC](../../../SPEC.md)。
