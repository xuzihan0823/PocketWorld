# 奶娃滑雪大冒险界面与画面约定

本模块在 PocketWorld 现有 React + Canvas 2D 卡带框架内实现冬日卡通界面，游戏入口、回调与房间电脑的缩放方式保持兼容。

- 卡带保持 800 × 600 逻辑画面，适配房间电脑和网页放大视图。背景源图为 1600 × 900（16:9），绘制时等比覆盖，不拉伸或改动碰撞空间；奶娃脚底基准位于左侧 240 像素。
- 初晴雪谷使用 #D5EDF6 冰雪蓝、#FFF9EC 奶油白、#F6AD49 橙黄；轮廓为蓝灰色，木牌为简洁暖棕色。暮色与极夜沿用同套分层的低对比配色变体。
- 标题使用本地托管的站酷快乐体「奶娃滑雪大冒险」七字子集，正文沿用系统中文字体。按钮不依赖图标或颜色单独表达动作。
- 首页、选道、暂停与结算使用覆雪木牌；主按钮为橙黄色，返回操作为次级文字按钮。首页显示简短键盘说明，木屋与奶娃位于木牌两侧。
- 天空、远山、树林与近景装饰为四个可独立使用的 SVG 图层，左右边缘连续，按 0.018、0.075、0.25、0.6 倍相机速度横向循环。图层不含角色、文字或按钮，近景灌木和小石块只占画面底部，不覆盖雪道；远山柔和，障碍轮廓清晰。
- 左上为距离和得分，顶部中间为金币与连击，右上为暂停。豆包距离与无限坐骑压缩成上方小提示，底部中央留空。桌面网页使用键盘，仅触屏设备显示右下半透明跳跃与收身按钮；嵌入窗口变窄时只调整排版与字号。
- 结算突出本次距离，其次显示金币、最高分纪录，再提供重玩与返回首页。全部图标为本地 SVG，不使用表情符号代替图标。
- 空中每完成一圈立即提供0.9秒小加速，用短促上扬音、金色扩散圈与身后气流确认，顶部小提示显示剩余加速；边缘速度线避开雪道中央。连续新圈刷新持续时间，不无限叠加，受撞击或摔倒取消；技巧分仍在安全落地时结算。落地雪浪、金币碎光与计数强调、摔倒星星分别反馈对应动作。粒子与音符数量受限，所有视觉计时由模拟驱动，暂停后冻结。
- 奶娃采用同一份低多边形几何的哑光着色，黄色身体、奶油白肚皮、红围巾、蓝护目镜。身体、腿和雪板保持独立 SVG 层，支持滑行、收身、起跳、翻转和摔倒的变换；白底三视图与 OBJ/MTL 源网格共享几何和配色。三视图和源网格不进入网页运行包。
- 身体与雪板绘制共用碰撞模型的旋转中心和姿势参数。头部、躯干及板端采样决定接地顺序，雪板接近竖直时仍可安全接地。原动作作为素材降级保留。
- 骑乘组合共用主角的父级旋转中心与完整翻滚角度，不给牛来另设小角度旋转。每个坐骑帧标定背部锚点，脚底严格锁定该点；归一化背部至地面的高度以沿用既有玩法尺寸。骑乘保持压低重心，屈腿围绕脚底缩放；空中暂停坐骑奔跑姿势，落地恢复。
- 电脑集成层将滑雪卡带呈现为可随视口缩放的放大画面。游戏模块不修改 body 或全局样式。
- 减少动态保留角色动作与危险信息，移除环境雪花和雪尘；暂停冻结全部游戏动画。四层背景按三雪道缓存为 800 × 450 画布，内存有固定上限。

字体许可见 `assets/games/ski/type/OFL.txt`。角色和音频来源沿用 `assets/games/ski/` 各素材目录许可。
