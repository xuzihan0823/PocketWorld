# 潮汐小馆 · `mario` 卡带

《潮汐小馆》接入原滑雪游戏的 `mario` 卡位，支持房间实体卡带和独立调试页。当前交付状态见 [进度文档](进度文档.md)，美术见 [DESIGN](DESIGN.md)，验证见 [验收标准](验收标准.md)。开工先读 [AGENTS](../../../AGENTS.md) 和 [SPEC](../../../SPEC.md)。

## 首版玩法

在一个海湾自动钓鱼，偶尔轻敲鱼竿加速。点击「码头」进入东湾街景。在「深海渔场大排档」点击室内的烤架、蒸笼或砧板，查看菜品的材料、用时和收入，选鱼后按份数制作。赚到金币后，到隔壁「渔具店」点墙上的鱼竿查看详情并购买。首次捕获点亮图鉴。范围为 **1 个海湾、12 种鱼、16 道菜、3 档鱼竿**；不做离线收益、后台挂机、多海域、养殖、店铺装修或操作系统桌面悬浮。借鉴 Steam《悠哉钓鱼》的循环，不使用其图像、界面素材、音乐或品牌。

| `snapper` | 红鲷 | 8 | 少见 | 是 | 5.2 / 2.5 |
| `squid` | 小鱿鱼 | 6 | 稀有 | 是 | 7 / 2.85 |

- **等口和收线**：每竿按权重抽取鱼种。等口时间为鱼竿的随机基础时间加鱼种追加值，赤曜深海竿遇到稀有鱼再减 2 秒。常见和少见鱼咬钩后自动收线，稀有鱼搏鱼成功后开始收线。鱼落到甲板才入鱼篓。收线期间可以暂停，去码头和图鉴需等鱼落船。鱼篓上限 32 条，满时停钓。
- **加速与搏鱼**：船上等口时按 `F / J / 空格` 或轻敲鱼竿，单次最多减 350 ms、累计最多减原等待的 30%，潮竹手竿冷却 250 ms，其余鱼竿为 200 ms，忽略键盘长按重复。稀有鱼上钩时进入 8 秒限时搏鱼，可按键盘或点屏幕上的 `D / G / C / N / Y`。按对加一格并换键，按错减一格（最低为零），满三格后自动收线。超时则脱钩，暂停、失焦、隐藏和宿主停用不消耗时间。
- **经营**：烤架有 6 道菜，蒸笼与砧板各有 5 道。普通寿司和盐烤鲜鱼接受任意鱼种，十二种鱼也各有对应的专属菜。双串烤鱿鱼和沙丁鱼手卷每份用 2 条对应的食材，其余菜每份用 1 条。详情按所选份数合计材料、用时和收入，最高份数受库存和剩余队列格数共同限制。确认时一次扣除整批食材并加入最多 3 单的队列。每份按顺序制作，完成后自动售出并入账。制作时间总计不含前面订单的等待时间。完整食材、用时和售价见 [配方表](catalog.ts)。
- **熟客点单**：船上的任务指南可查看本趟熟客和所需食材，大排档桌上的点单簿翻开后显示客人、上菜份数、小费和各道可选菜的食材，点菜名会打开对应工作台。四位熟客按顺序到来，可自由制作菜单内的其他菜。符合当前点单的菜完成售卖时才计入进度，交齐后将小费自动加入金币与营业额。首位客人点两份盐烤鲜鱼，售价合计 12 金币，小费 8 金币，恰好够第一档升级。点单进度与营业额一起按趟重新计算，未售订单仍和鱼篓一起保存。
- **会话**：首页 → 现在上鱼！ → 暂停或收工结算 → 返回首页。船与码头之间播放约 1.8 秒的航行镜头，期间冻结鱼竿和订单计时，船上推进钓鱼，打开任务指南时暂停计时。码头、店铺和图鉴暂停鱼竿计时，订单继续售卖。回船后从剩余时间继续，换过鱼竿则用新竿重新抛线。首页、内部暂停、结算、隐藏、失焦、收起、外部停用和拔卡停止推进。恢复不补算；新趟营业额归零，金币、鱼篓、图鉴、竿级和未售订单保留。目标是本趟营业额 ≥20；升级花金币不扣营业额。收工只结算一次，`victory` 表示是否达成目标。

| 鱼竿 | 解锁价格 | 基础等口 | 特点 |
|---|---:|---:|---|
| 潮竹手竿 | 初始装备 | 10–14 秒 | 竹色手竿，无绕线轮 |
| 青鳍海竿 | 20 金币 | 8–11 秒 | 青绿色配小轮，轻敲冷却降到 0.2 秒 |
| 赤曜深海竿 | 55 金币 | 7–9 秒 | 赤铜色长竿带金色轮，稀有鱼额外提前 2 秒上钩 |

鱼竿按顺序解锁，购买后自动装备。已购鱼竿可免费更换。

## 重量、鱼饵与钓鱼生涯

- 鱼按各自的重量范围生成个体克数，同种鱼的重个体会多收线 0.6 秒。鱼落船时放大展示渔获卡，列出鱼名、稀有度、重量、使用的鱼饵和累计捕获次数。卡片可收起，也会自动消失。
- 船上可用鱼饵袋选饵，渔具店的鱼饵柜可以补充。初始送虾肉饵和鲜鱼块各 3 份。虾肉饵每竿少等 1.5 秒。鲜鱼块提高同种鱼中重个体的概率。已抛出的鱼线沿用当时使用的鱼饵，选中的饵用完后自动改用空钩。
- 从首页、船上或收工页进入钓鱼生涯。荣誉室显示最大渔获的鱼种和重量，以及各鱼种累计捕获次数。生涯数据从支持称重的版本开始累计，旧版图鉴、鱼篓与经营数据会迁移。

## 场景声音

首页和图鉴共用海湾主题动机，船上是稀疏拨弦和潮声，航行叠加尾浪，码头加上栈桥轻响，渔具店是室内拨弦，大排档以轻拍和灶火声作底。搏鱼使用更快的节奏和风声，收工回到短曲。抛竿、收线、登岸、进店、翻图鉴、选菜、做菜和到账都有相应短音效。点击「现在上鱼！」后播放船上音乐。音频由单个 Web Audio 上下文合成，通过宿主静音控制，暂停、停用和卸载时停止。

## 替换契约

| 项目 | 替换后的约定 |
|---|---|
| 模块与实体 | `src/games/mario/index.tsx` 默认导出 `MarioGame`，严格实现 `GameCartridgeProps`。`GameId`、`game-cartridge-mario`、桌面架位、共享外壳、单槽和 CRT 均保留。只改这张卡的显示名、必要徽标与识别文案。没有 `fishing` ID 或额外架位。 |
| 页面 | 普通链接仍进房间；`?dev=mario` 懒加载独立调试页，不加载 Three.js、GSAP 或房间。旧 `?game=ski` 保留为房间的 `mario` 选卡链接，打开替换后的钓鱼而不是恢复滑雪。`?dev=shooter` 行为不变。 |
| 游戏交互 | Canvas 2D 逻辑尺寸 800×600；外层等比显示。活跃时 `Esc` 先关闭当前详情、备货台、点单簿或渔获卡，再从店铺返回码头、从码头或图鉴返回船上，船上暂停，暂停继续，结算返回首页；首页 `Esc` 不拔卡。只有首页「退出」调用 `onExit()`。停用不拦宿主按键。保留聚焦按钮原生的 Enter/Space。 |
| 成绩 | `onScoreChange(score, highScore)` 随营业额变更去重上报；首次或新趟可同步一次。`onGameOver` 只在收工后上报一次。钓鱼使用 `pocketworld:mario:highscore:v2`（非负安全整数文本），独立页和房间一致。旧 `pocketworld:mario:highscore` 是滑雪记录，**保留，不读取、不覆盖、不迁为钓鱼成绩**；`shooter` 成绩键不变。 |
| 进度 | `pocketworld:mario:save:v2` 保存经营进度、竿级、鱼篓、发现的鱼种、待售订单、鱼饵与生涯统计。旧 `save:v1` 只读取，首次写入使用新键。售出移除订单与增币以同一快照保存。同站点另一页更新存档后，旧会话暂停，可点击「载入最新进度」重新开始。存档和成绩合计 ≤4 KiB UTF-8。 |
| 落盘与停止 | 捕获、备货、售出、升级、结算及时保存，暂停、停用、`pagehide` 和卸载仅保存脏数据；不逐帧写。损坏、未知版本、读写被拒均不崩溃，未知版本不覆盖。静音立刻停声；停用取消游戏循环与计时器并停声，卸载移除监听且关闭 `AudioContext`。 |

## 调试与文件职责

- `catalog.ts`、`engine.ts` 和 `model.ts` 定义鱼种、配方、可确定性推进的游戏状态和数据接口。
- `FishingGame.tsx`、`session.ts`、`storage.ts` 和 `audio.ts` 处理输入、时钟、存档及音频生命周期。
- `FishingView.tsx`、`renderer.ts` 和 `view.css` 渲染游戏场景、菜单和操作状态。素材集中放在 [assets/games/ski](../../../assets/games/ski/README.md)。
- `?dev=mario` 可直接试玩并检查静音、停用、装卸与成绩。改动后运行 `npm test`，发布前按 [验收标准](验收标准.md) 复测。
