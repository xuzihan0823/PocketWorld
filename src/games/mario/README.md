# 奶娃滑雪大冒险

奶娃自动沿雪坡滑行，跳过圆石、收身穿过树枝，在空中翻转赚取技巧分；牛来提供贴地滑行和骑乘冲撞两种伙伴能力。摔倒会让后方的豆包群逼近，豆包身体触及奶娃时结束本局。

两种牛来坐骑均可无限骑乘，不按时间或距离到期。滑行形态挡下一次撞击后离开；冲撞形态可持续撞碎圆石，撞到树枝等造成摔倒的情况会结束骑乘。被豆包抓住也会结束骑乘。三条雪道均已移除雪洞，保留连续雪面、冰面和跳台。

骑乘时主角压低重心，脚底固定在牛来每帧的背部接触点；两者共用同一个旋转中心与完整翻滚角度。空中暂停牛来的奔跑循环，落地后继续，避免一边翻滚一边跑动或相互脱离。收身与落地缓冲只调整主角上半身和屈腿幅度，脚底不离开坐骑。

## 操作

- W / 空格 / 触屏跳跃：轻按起跳，继续按住后空翻，松手辅助摆正。
- 空中每完成一整圈，立即获得0.9秒小加速；连续完成新的一圈刷新持续时间，速度最高470像素/秒。同一圈来回摆动不会重复领奖，安全落地后再结算技巧分；摔倒、坐骑挡下撞击或被抓住会取消加速。
- A / D：空中调整角度。
- S / 触屏收身：地面低姿通过树枝，空中快速下落。
- 摔倒后连续轻按跳跃：加快起身。
- Esc / 暂停：冻结本局；菜单仅含继续与返回首页。暂停时再按 Esc 继续，选道时按 Esc 回首页，首页按 Esc 退出到电脑。

直接访问项目 URL 的 `?game=ski` 可打开独立游玩视图，退出后回到房间；也可在房间电脑插入「奶娃滑雪大冒险」卡带。

首页 → 选择初晴雪谷、暮色松林或极夜冰原 → 无尽滑雪 → 结算，可同雪道重玩。首页退出才调用 `onExit`。

落地按头部、躯干与双板的二维碰撞体积判定。雪板端点或板底先触雪时进入连续回正和屈腿缓冲，接近竖直的雪板也可落稳。头部或躯干先撞雪、撞到障碍会摔倒。石头与树枝同时检查身体和雪板的移动路径。

## 集成

保留 `mario` 卡带标识、`index.tsx` 的 `MarioGame` 默认导出及 `GameCartridgeProps`，使用 800×600 Canvas 2D。纪录键为 `pocketworld:mario:highscore`，分数和单次结算通过既有回调上报。外层停用、窗口失焦、页面隐藏会暂停，回来后需主动继续；卸载清理动画帧、输入监听和音频。

房间电脑沿用集成层的 `ComputerScreen`，支持放大、回到电脑与手机视口自动放大；独立入口使用 `CartridgePlayer`。`?dev=mario` 也可直达滑雪游戏。游戏 CSS 限定在自身类名内，无新增依赖。

奶娃分层 SVG 在加载时解码并缓存；豆包采用原图第二行八帧；牛来使用已有双形态序列图。仅绊倒和被豆包抓住时触发笑声，从原始 WAV 开头播放三秒；翻转不播放笑声；骑乘播放完整 `niulai.wav`。失败素材提供备用人物与重试入口。

游玩姿势采用 `assets/games/ski/naiwa/ski-volume-rig.svg`，由本地低多边形几何生成哑光卡通外观，保留黄色奶娃、浅色肚皮、围巾与护目镜的识别特征。身体、腿、雪板独立控制，收身通过前倾和屈腿降低高度，碰撞与绘制共用旋转中心和姿势参数。分层素材失败时加载原动作作为降级。白底三视图及 OBJ/MTL 源网格保存在同目录，仅用于美术制作。

界面采用冰雪蓝、奶油白与橙黄按钮，首页和结算使用覆雪木牌。桌面使用 W / 空格跳跃、S 收身、A / D 空中微调、Esc 暂停；仅触屏设备显示半透明操作按钮。运行在房间电脑的小窗口或放大视图时，均按实际容器缩放。四个 16:9 循环雪景源图位于 `assets/games/ski/winter/`，游戏仍使用原有 800×600 卡带尺寸。

翻滚奖励有金色扩散圈、身后气流、边缘速度线、短促上扬音和加速余量提示；落地有轻雪浪，金币有金色碎光、数字强调和轻叮声，摔倒有环绕小星星。粒子不超过80，提示音同时最多4个，无额外素材或依赖。所有特效跟随游戏时钟暂停；轻柔动态关闭装饰粒子、速度线和闪动，但保留加速、计分和文字提示，静音立即停止提示音。
