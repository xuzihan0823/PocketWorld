## 人物光脚行走音效（2026-11-07）

为人物补充光脚踩在木地板（及观景舱地毯）上的程序化脚步音效：

- 在 `src/scene/audioEngine.ts` 新增 `roomAudio.playFootstep`：以脚跟肉垫触地引发的温润木板低频短促共鸣（正弦+三角波快速下潜）、约 `20ms` 后前脚掌裸肤轻拍木面的肉感瞬态与带通/低通粉噪层组合，模拟光脚踩在橡木地板上的自然“噗嗒”声；支持左右脚音高微差与细微随机扰动，区分木地板（`wood`）与观景舱地毯（`rug`），并提供普通行走（`walk`）、起跳/转椅蹬地（`push`）及双足落地（`land`）三种姿态包络。
- 在 `OrbitalResidents.tsx` 将脚步声与行走步态相位 `gait` 同步（每半周期 `π` 弧度触发一次），起身落脚、跳跃起落与转椅光脚蹬地同步触发对应音效；在移动按键、物品快捷键与轨道画布/地板点击手势中调用 `roomAudio.unlock()`，受全局静音状态控制。
- 落地按上一帧离地、本帧接地判断，不再依赖最后一帧的高度阈值；轨道角色腾空移动时保留步态动画但不播放行走音效。起跳/落地分别去重，普通行走声避让刚发生的接触动作。

整合验证：脚步音效 12 项及电脑退出/展示状态 13 项测试通过；连同游戏、卡带和生产接入检查，共 128 项测试通过。原脚步分支的 23 项测试记录中，12 项脚步回归测试执行真实组件帧回调、按键处理及音频事件节流，覆盖两套角色在 60/120/144/240 FPS 下每次跳跃只触发一次落地、腾空移动、撞墙与恢复移动、B 键同步解锁、快速接触去重及静音；其余 11 项为电脑退出回归。`npm run build`（含 TypeScript 检查）通过，仍有既有 Three.js 大包提示。测试使用 hooks/音频替身，不代替 Safari 自动播放策略、实体手机与扬声器听感验收，这些仍未验证。

## 电脑退出修复

电脑聚焦后，只有已加载且实际激活的游戏接管 Esc。空卡槽、读取中、模块缺失、加载或运行失败、电脑拨杆暂停及拔卡动画期间，Esc 直接退出电脑并返回房间。正常运行的游戏仍独占 Esc，用于其内部暂停菜单。

Esc 与电脑侧把手共用退出处理：取消物品传送、清空卡带选择并触发原有返回镜头；已取消插卡动画的迟到回调不能重新插入卡带。未增加可见按钮、公共接口或运行依赖。

验证：`node --test src/scene/orbital/media/media-exit.test.mjs` 的 11 项本地状态测试通过，覆盖空电脑、缺失/读取/导入失败、运行失败、拨杆暂停/恢复、拔卡、侧把手、取消插卡及监听清理。这些测试执行真实组件的事件与副作用，使用轻量 hooks 和场景替身，不等同于真实 WebGL 或完整浏览器验收。首次测试发现 Node EventTarget 的布尔 capture 移除行为差异，夹具已规范为 capture 对象；未因此修改产品逻辑。浏览器已能进入电脑，但 Esc 验证被自动审批拒绝，本轮未绕过；鼠标/触屏返回、镜头最终位置与恢复行走仍需实机确认。最终构建结果见 PR。

## 2. 本轮具体改动

### 2.1 连续操作、事务和镜头

`useWorldController.ts` 仍沿用准备、进入/离开、提交、返回和错误状态，不重写整个交互系统。

1. **灯绳快速拉两次**：第二次按用户已经看到的状态计算，而不是先回滚后再次读取旧状态。`toggle`、`open`、`sleep`、`sit` 和 `turn-page` 保留这一意图；失败仍可回滚到事务快照。
2. **开门后立刻取盒子**：取出收纳盒时保证柜门处于打开状态；关门时同时收回盒子。修复“盒子出来但门关回去”的不一致。
3. **坐卧互斥**：躺下解除椅子占用；坐下解除床占用和床特写；跨舱解除坐卧状态并触发适用的唤醒回调。
4. **睡眠失败回滚**：还原对象状态时也恢复睡眠会话引用。
5. **快速翻页**：进入阅读的镜头过渡尚未结束时翻页，仍保持书本打开及阅读焦点。
6. **普通物品操作不抢镜头**：开抽屉、翻页等不改变焦点的动作不再把用户视角强制复位。
7. **观景舱书本特写**：补上书架位置差异，镜头目标与实际书本对齐。

状态探针运行在浏览器内的隔离 React 根中，调用实际控制器；它不是修改主场景状态的替代验收。柜体、床、椅子等另有真实鼠标操作验证。

### 2.2 手机输入

- 修复竖屏首次加载时使用错误相机的问题，首屏按宽高比计算视距。
- 用容器上的原生触摸捕获统一接收画布与 Drei HTML 书页事件，避免不同 React 渲染根造成返回手势失效。
- 双指轻触返回要求短时、无明显位移；有移动距离的捏合不会误触返回。
- 书页设置横向手势归应用、纵向滚动归浏览器，修复滑动被浏览器 `pointercancel` 取消的问题。
- 多指操作不再被当成单指翻页；移动端纸面字号和提示可读性已调整。
- 没有新增可见按钮。文件选择由空白唱片触发隐藏的原生文件输入。

### 2.3 家具、材质和资源管理

- 椅子坐垫和靠背使用中心鼓起、边缘收薄的软垫曲面，而非仅调整盒子颜色。
- 新增 `Materials.ts`：木材用共享程序化木纹，床品和椅垫使用共享织物凹凸材质；保留既有配色。
- `Tube` 改为按稳定形状参数复用几何体，并清理独占几何资源；不因父组件每次重绘都重建。
- 床品和新增软垫也显式清理独占几何；共享材质不随单个实例误释放。
- 保留已接入的盆栽与抱枕 GLB。未使用的扶手椅仍保留在资源目录，本轮没有删除它。

### 2.4 绘制优化

- 保留地板每块板的轮廓、拼缝和颜色，合并为带顶点色的几何体，而非 68 个独立绘制对象。
- 实体键盘现为 77 键紧凑布局，实例化键帽与一张程序生成的标识图集，保留位置和颜色区别，并同步真实键盘的下压与回弹。
- 不活动的舱室不绘制，切换时再显示相关场景。
- 未新增后处理依赖、未提高 DPR 或阴影贴图规格。

### 2.5 宇宙光照与素材

- 宇宙背景全部由 three.js 着色器实时生成，不再加载星图或地球贴图：天球着色器绘制银河带、尘埃暗带、缓慢流动的星云和太阳光晕；7000 颗星为单次绘制的点精灵，按色温着色并各自闪烁，亮星带衍射星芒；流星从当前视野附近随机划过。
- 地球的海陆、冰盖、干旱带、夜面城市灯光和云层均为程序噪声，地球缓慢自转，云层另有独立漂移；海陆形状是虚构的，不对应真实地理。
- 开启“减少动态效果”时宇宙时钟停止，流星不再生成。
- 地球与舱室共用太阳方向。修复观景舱平移后定向光仍指向世界原点的问题：光照目标现在随舱室挂载。
- 这是有真实资料来源和一致光照方向的艺术化轨道场景，不是轨道动力学、人工重力或物理大气散射模拟器。

### 2.6 游戏、电脑屏幕和卡带集成

- 游戏按需加载，电脑屏幕使用投影到整像素 4:3 区域的 DOM，移除文字透视缩放链；失焦暂停并保留实例，拔卡卸载。
- 单击卡带只聚焦电脑；按住并拖到右侧卡槽附近松手才装入，其他位置归位。碰撞限位不会把桌下松手误判为有效插入。

## 6. 性能与构建结果

### 6.1 可比较的测量

- 同一桌面生活舱机位：绘制次数从 **414 降到 315**，减少 99 次，约 **23.9%**。
- 三角形从约 173,916 变为 176,996；优化重点是合并绘制，而软垫曲面增加了少量三角形。不能声称三角形数量也下降。
- 干净初始状态测得几何体 258、纹理 12。
- 在已经导入歌曲、走过两舱的状态下，连续四轮打开/退出日记，几何体数量 **343 → 343**。这证明该复现路径下不再持续分配，不代表长期压力测试完成。
- 其他状态曾测得 298 次绘制，但唱片架页数、可见物体与姿态不同，不用该数值冒充同机位优化结果。
- 不报告未经测量的 60 FPS 或实体手机性能。

### 6.2 构建与检查

- `npm run build`：通过，包含 TypeScript 检查和 Vite 生产构建。
- `git diff --check`：通过。
- `npx impeccable detect src/scene/orbital`：命令成功，19 个文件按正则规则扫描；未运行需要页面解析的低对比度/小字号规则，不把它当完整可访问性通过。后续新增/修改需按范围复检。
- 当前 Three.js vendor chunk 约 **971.96 kB**，gzip **268.32 kB**，仍有超过 500 kB 的构建警告。没有通过修改警告阈值掩盖问题；独立游戏沙盒不加载该包。
- 最终无头浏览器回归路径没有新增应用运行错误。开发中出现过测试脚本用错选择器、过时相机引用及热更新保留旧 ref 形状的问题；已重新加载后复测，不把旧日志混作最终错误。
