# 轨道居住舱模块进度

主要实现：`src/scene/orbital/`、`src/types/world.ts`、`src/App.tsx`、`src/scene/audioEngine.ts`、`assets/public/models/`。

场景职责见 [模块说明](../README.md)，交互和存储约定见 [SPEC.md](../../../SPEC.md)，验证方法与历史记录见 [验收记录](验收记录.md)。

## 当前已实现

- **站立待机**：6 秒淡入呼吸、头肩与肩臂放松；20–30 秒首次环顾，之后间隔 24–36 秒；50–70 秒首次 Yawn，之后间隔 65–95 秒。6.33 秒环顾与 8.33 秒 Yawn 均按需加载、完整播放一次再回普通待机，互斥且至少隔 8 秒。仅写上身旋转，脚与骨盆沿用中立站姿；移动、交互和减少动态效果沿用同一打断逻辑。真实房间已检查正侧面姿态、结束回普通待机、行走与 E 拉抽屉打断，浏览器无错误/警告。数值检查覆盖两种动作频率、足部固定、走停衔接及减少动态效果。依赖 PR #59，未覆盖其普通待机增强；#57 站姿修复合并后的整体回归待队长集成。
- **Luna 上床三版（IK 重建）**：复用床的 sleep/wake、走近与返回流程，在 `luna-bed-v3.blend` 内为双臂与双腿建立 2-bone IK + Pole 目标与解剖学关节限位，第 0 帧精确匹配运行态中立站姿，重做从微屈膝预备、床沿手撑落座、左腿先导右腿错拍屈膝上床到肩背缓冲落枕的全身过渡与裙摆/发束跟随，消除关节轴向扭转、脚刮被面及身体穿床。独立动画 GLB（799,616 bytes，115 节点 / 230 通道）按需加载，外层根固定，睡姿保持，醒来/取消逆向退出后恢复普通行走。制作源与复建方式见 [素材说明](../../../assets/models/resident/README.md)。
- **空间与无按钮交互**：等轴测轨道生活舱（含装饰舱门；观景阅览舱代码保留但当前无外部入口），在房间内靠近物品按 `E`，进入近景后用鼠标操作当前物品（`M` 静音、`Esc` 返回），主界面保持零可见按钮。
- **宇宙背景与材质**：天球渐变、地球眺望、9000 颗星空与 160 颗漂浮粒子全部由 Three.js 着色器生成（支持 `prefers-reduced-motion`）；地板合并绘制，木纹与织物使用共享程序化材质。
- **轨道昼夜（太阳周期）**：太阳沿经过地球背后的大圆运行，压缩轨道周期 8 分钟一圈，其中约 20%（约 96 秒）处于地影（`sunCycle.ts`）。太阳靠近地球时放慢角速度，使地影足够长且太阳确实藏在地球圆盘后。同一份太阳状态同时驱动天空太阳光晕、地球昼夜分界线与夜面城市灯光、大气边缘日出日落光环、星空亮度，以及舱内主光的方向、颜色、强度、半球环境光和环境贴图强度。舱内主光沿用太阳方位但仰角不低于 0.3，避免从地板下方打光；太阳贴近地球边缘时主光转为暖橙色，进入地影后只剩台灯与冷色补光。每次进入从原来的固定太阳方向开始，约 2 分钟后第一次日落。`prefers-reduced-motion` 下太阳停在起始位置；`?sun=` 与 `?sunSpeed=` 用于调试（见 `SPEC.md` 第 7 节）。
- **家具模型替换与机关**：13 个家具部件（`assets/public/models/replaced/`）接入现有运动父节点，支持局部回退；抽屉的木质面板和黄铜拉手随托盘一体滑动，支持靠近后退避让、椅子占位校验与碰撞阻挡；柜门与收纳盒联动；台灯、盆栽（接照料反馈）、床与椅子坐卧互斥，转椅在近距离各方向都可按 `E` 选中；Luna 沿可行走路线到椅子当前正面对齐并坐下，必要时先让开，再等椅子后移腾出入口。坐下后可通过 `WASD` 蹬地滑行。
- **团子**：猫窝上的团子使用 [猫模型](../../../assets/public/models/cat/cat.glb)，按猫窝尺寸缩放并对齐坐垫。靠近团子按 `E` 摸猫。模型骨骼驱动转头与摇尾，摸猫时有弹跳和粒子反馈。
- **住民角色与动画**：采用 `assets/public/models/resident/luna-walk-room.glb`（115 骨骼、1 秒行走循环），按实际位移推进步态与程序化光脚音效，支持跨房间独立骨骼、站/坐/卧及书柜取放阅读动画。生活舱转椅使用 Blender 坐姿与局部接触缓存；Luna 落座过程中将髋部往坐垫里送约 12 cm，坐稳后 1.5 秒升高 8 cm，滑行或起身前先缓降；原行走片段继续复用。角色恢复原始 4K 底色，减弱法线并用底色补光，以减少近景脸部块状暗纹。肤色在共享贴图中单独做柔和的暖桃色校正，并略降皮肤的自发光，保留蓝发、服装色和原有五官细节。Luna 日常空手，走到书柜即可选书或取指定书。
- **电脑、实体键盘与游戏卡带**：电脑键盘用内置 77 键整洁底座，键帽与字母贴合，仅在与电脑交互（聚焦电脑）时随物理按键同步下压，停用的扫描键盘模型已移除；`mario`（奶娃滑雪大冒险）与 `shooter`（团团魔法录）双卡带底部贴合桌面，在全景或电脑近景点击或轻触即可自动入槽并按需加载，电脑近景也可手动拖入卡槽，`ComputerScreen` 投影整像素 `4:3` 区域，窄屏自动放大并处理 `Esc` 退出隔离。
- **日记、日程与书柜**：
  - 日记本用连续书脊和实体书页，支持页角或左右方向键翻页，逐页编辑正文、日期和天气并自动保存，兼容旧存档。
  - 书柜支持内置书、自定义添加、翻页阅读与本地持久化。三本内置书并排放在中间层，旧存档同步排列，仅移动占用新书位的自添书，保留正文和阅读进度。取放与阅读动作采用全身 IK 协同（视线跟随、肩肘与躯干引导、正交手掌基准与指尖贴合、底层屈膝足底锚定、高层挪半步抬肩伸臂），书脊抽取、Hermite 弧线抱书、封面掀合、双向弯曲纸页轨迹与直线推入之间连续衔接，共用同一套手书接触坐标。
  - 日程本支持双任务页、时间输入、上拖贴玻璃（上限 5 张）、`V` 切换视角、揉纸丢弃（地面上限 24 个）与离线/重试保护。
- **音乐唱机与导入**：内置 Web Audio 合成预设唱片，进入唱机近景后支持点击选碟或拖入本地音频生成实体光盘、播放/暂停/静音及跨焦点后台播放。唱片保持架上原尺寸，按固定架位取放；换片串行执行抬臂、减速、旧片归架、新片弧线入盘、同轴旋转、落针与音乐淡入。动画期间忽略重复点击，导入唱片保留并顺序处理最近一次播放请求。
- **桌面分区布局**：桌面物件按左侧音乐区（唱片机、唱片架、空白导入唱片）与右侧电脑区（显示器、键盘、游戏卡带、卡槽、暂停拨杆、音箱）归组；空白导入唱片贴近唱片机，两张卡带在显示器左后侧前后错开成组，日程本与键盘后收，中部留出可见木纹间隔、前沿保留连续操作空间。日记本保留在左前原位（翻开书页需占用唱片机与桌沿之间的空间）。本轮仅调整物件位置与必要的交互定位，未新增/删除/缩放模型，未改桌体、椅子、灯光、材质与正式镜头。

## 验证状态

- **近距离入口与鼠标操作**：桌面 Chrome 已验证椅子接触前不滑动、贴近后可推、椅子旁的桌前站位按 `E` 进入电脑。房间内点击屏幕不能进入电脑，进入后可点击卡槽。另验证 `E` 进入日记、日程、唱机、柜门及藏书，唱机空白唱片可打开文件选择器。

- **卡带贴桌与单击插卡**：回归覆盖两张卡带贴桌、搬运时避开显示器和另一张卡带，以及全景选择后等待电脑转场再入槽。其他物品近景不接收卡带操作。桌面浏览器验证全景与近景单击、近景拖入、拔出归位及槽外松手归位。实体触屏待验证。

## 已知限制与待验证

- **墙体显隐**：舱室已补全前墙并把左右墙延长到整个进深，镜头放开为 360° 水平环绕。墙体按遮挡关系淡入淡出（`walls/`）。不随墙体淡出的部分：右墙门洞里的舱门模型（家具资源）以及贴地的窗台、踢脚灯带，这些仍然显示。补全的墙体在不透明时会投射阴影，按太阳方向推算，左侧床位一带会比原来的开放式剖面略暗，尚未逐项比对确认。从背面镜头直接切到物品聚焦时，镜头沿直线飞行，会短暂穿过已经淡出的墙。真实 GPU 上的帧率与触屏手势还没有验收。
- **上床与坐卧**：醒来使用当前动作逆放，未新增独立起床、闭眼或循环睡眠；当前检查针对定型床姿与全 223 帧几何接触审计，Round 3 最新导出包的桌面浏览器实机视觉回归及通用布料/头发物理碰撞尚未验收。
- **顶层取书接触**：当前 Luna 尺寸与取书站位下，六个顶层书位的伸手终点，实际骨架手掌距预定抓握点仍约 0.085–0.107 个场景单位；动画可完成抽出，但手掌未贴住书脊。需另行调整靠近距离或取书姿态，本次只调整默认书排列。
- **轨道昼夜**：舱内主光的最低仰角是为可读性做的取舍，低角度日落光不完全对应真实地球方向；补全墙体后不同太阳方位下的室内明暗、窗口光斑与夜间亮度只在桌面 Chromium 预览中抽查过关键相位，未逐相位比对，也未在实体手机上验收。
- **端到端未验收环境**：实体手机（iOS/Android）、Safari 浏览器、软键盘遮挡、屏幕阅读器完整流程及低端 GPU 长时间运行尚未验收。
- **卡带静止高度**：两张卡带静止时底部约高于桌面 0.085（与搬运路径的离桌间隙一致），属既有状态；本轮仅改 x/z 归组，未改 resting 高度，如需贴合桌面须另行评估搬运测试的离桌不变量。
- **功能边界**：日程远程同步适配器尚未接真实后端；门外观景舱当前无激活入口；角色未实现表情形变、逐指抓握与布料/头发物理；部分家具近景模型精度与总包体体积仍待进一步压缩优化。
