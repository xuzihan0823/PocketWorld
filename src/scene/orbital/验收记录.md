# 轨道居住舱场景 · 验收记录

按功能记录已经做过的验证：用了什么方法、覆盖了哪些路径、没有覆盖什么。模块的当前状态和待办见 [进度文档](进度文档.md)。

记录里的「通过」只对写明的方法和路径成立。无头浏览器、触摸注入和测试替身的结论，不代表实体手机、Safari 或人工试听已经验收。测试项数是记录当时的数字，当前数字以 `npm test` 的输出为准。

## 验证方法

1. 真实鼠标：抽屉、柜门、收纳盒、床、椅子、唱片和旋钮。
2. 真实键盘：住民移动与跳跃，日记、日程、书籍快捷入口及双向翻页；日程的 `V` 切视角、左右键浏览玻璃页，以及输入时的快捷键隔离。
3. 浏览器文件上传：临时生成的测试 WAV，该文件不进入仓库。
4. 拖放：有效音频和无效文本文件，分别得到播放或明确的错误提示。
5. Chromium CDP 触摸事件：双向滑动翻页、双指返回、捏合不误返回。
6. 控制器隔离探针：在浏览器内的隔离 React 根中调用实际控制器，覆盖快速拉灯绳、快速取盒、关门收回、坐卧互斥、适配器准备失败回滚。探针不替代主场景的真实操作验证。
7. 数值检查：太阳单位方向约为 `[-0.534522, 0.801784, 0.267261]`，两舱一致。
8. 循环资源检查：导入歌曲后连续四轮打开和退出日记，几何体数量 343 → 343。

## 电脑、卡带与小屏幕

- 卡带：浏览器实测单击不启动、屏幕与桌下误放归位、正确装入、退出归位和重复装入。评审截图：[卡带装入游戏](./review/cartridge-inserted.jpg)。
- 小屏幕：生产构建在浏览器中用键鼠完成 320×568 插卡、选装、战斗升级，再依次切换 390×844、844×390、1280×720，验证重抽、同职业换枪、暂停、放大与收起、内嵌继续、首页、手记、拔卡和返回房间；过程中同一局数据保持，且只有一个游戏根节点。详见 [团团魔法录修复验收](../../games/shooter/survival/PR7修复验收.md)。
- 电脑退出：自动测试覆盖空电脑、缺失、读取中、导入失败、运行失败、拨杆暂停与恢复、拔卡、侧把手、取消插卡及监听清理。测试执行真实组件的事件与副作用，使用轻量 hooks 和场景替身。测试夹具把监听的 capture 参数规范为对象形式，以适配 Node 的 `EventTarget`，产品逻辑未因此修改。
- 未覆盖：原生手机触摸、安全区设备与 Safari；`Esc` 退出电脑的浏览器实按，以及鼠标与触屏返回后的镜头最终位置和恢复行走。

## 住民模型

- 模型从 77.73 MB、1,497,798 面处理为 8.26 MB、168,728 面，保护正脸顶点，颜色贴图 2048、法线贴图 1024，不需要外部解码器。
- 材质与造型精修：调整冰蓝发色与偏暖肤色；修顺鼻口至下巴的 5,548 个顶点并重算法线；修圆两侧脸颊和下颌衔接，调整 5,350 个顶点。UV、拓扑和贴图不变，没有新增零面积三角形。评审截图：[发色、肤色与鼻口精修](review/resident-color-comparison.png)、[脸颊与下颌修圆](review/resident-cheek-comparison.png)。
- Chromium 真实键盘：移动、跳跃后落地、`E` 坐椅、`B` 躺下及恢复站立通过；重新加载模型正常，没有页面运行错误。检查坐姿时把椅子移到空旷处，仅用于检查夹具，没有写入默认场景。
- 数值：移动约 0.538；跳起采样 y=0.627 后落地归零；转椅驱动 1.2 秒移动约 0.447；脚底接地采样 y≈0.001，恢复抬脚 y≈0.039–0.071。
- 独立 Canvas 注入一次加载失败后，占位与重试恢复成功，StrictMode 下骨骼正常。
- 已查看 1280×720 桌面、390×844 竖屏，以及站立、坐姿、平躺近景。正常重载没有应用控制台错误和失败请求。
- 上述检查在九根骨骼的版本上完成。书柜交互把骨骼扩展到十九根并重建双臂，相应验证见 [书柜交互验收](../../../docs/书柜交互验收.md)。
- 未覆盖：手和玩偶保持源姿态；没有眨眼、闭眼、头发和布料物理；实体手机、Safari、极端姿势下的穿插与长时间运行。

## 性能测量

- 合并地板与实例化键帽后，同一桌面生活舱机位的绘制次数从 414 降到 315，约减少 23.9%；三角形从约 173,916 变为 176,996，没有下降。
- 住民 GLB 接入后，同机位为 281 次绘制、328,318 面，几何体 225、纹理 11。绘制数下降，面数增加。
- 这些都不是持续压力测试或手机帧率验收。书柜与双臂重建之后没有重新测量。
- `npx impeccable detect src/scene/orbital` 按正则规则扫描通过；没有运行需要页面解析的低对比度与小字号规则，不能当作完整的可访问性通过。
