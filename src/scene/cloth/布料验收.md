# 桌面布料验收与路线判断

**本轮结论是继续单袖 XPBD 预研，保留 Rapier 对照，暂缓正式接入。** 同机走路时，XPBD 的单袖求解均值为 0.69 ms/渲染帧，Rapier 为 4.80 ms；悬挂布剧烈折叠时，Rapier 对自由边伸长的控制更好。真实袖子的结果同时暴露了两个后端共用的资产问题：弯肘时代理易拉长，躺下时袖面与碰撞壳仍有明显重叠。正式选型需复验袖子与真实衣身的表面接触。

## 同一条物理轨迹

同一块 12×9 布、固定顶边、同一障碍球，锚边周期收拢、前后折叠、横向快速换向。分别在两个后端积分 240 个 1/120 秒子步，每 6 步取样。拉伸统计排除两端均受运动学驱动的边；折角是共享边相邻三角形法线夹角的均值，再取整个过程的峰值。开启或关闭自碰撞均能将固定点误差控制在 0.1 mm 的测试容差内。

| 后端 | 自碰撞 | 自由结构边最大伸长 | 平均折角峰值 |
|---|---|---:|---:|
| XPBD | 开 | 112.4% | 43.9° |
| XPBD | 关 | 123.8% | 43.3° |
| Rapier | 开 | 43.2% | 40.3° |
| Rapier | 关 | 39.3% | 42.3° |

两者都能弯曲并随锚点反转。XPBD 的五轮投影在强制折叠下仍有较大的瞬时伸长，当前材料参数不能满足高抗拉布料。XPBD 的重合非邻接粒子有单独的开关回归；Rapier 使用其原生可变形表面自接触。表面折叠时还需用连续三角形相交检查验证漏碰，当前粒子重叠计数覆盖不到薄片边缘相互穿越。

## 真实单袖与动作切换

左袖含 60 个代理粒子与 1,833 个候选映射顶点。每个后端观察完整 34.25 秒轮播，36 次约一秒间隔的快照覆盖全部姿势；每次取其中 123 个真实表面顶点比较原始蒙皮与校正结果。下表为各动作内的快照最大值，单位 mm。两个后端的取样时刻随浏览器调度略有偏移。球壳随骨骼移动，测得的深度表示该碰撞近似下的残差；模型没有单独的高精度裸体参考表面。

| 动作 | XPBD 原始蒙皮 → 校正袖面 | Rapier 原始蒙皮 → 校正袖面 |
|---|---:|---:|
| 待机 | 33.2 → 31.3 | 33.1 → 31.2 |
| 行走 | 46.4 → 34.9 | 48.1 → 36.8 |
| 抬臂 | 43.1 → 28.8 | 42.3 → 29.1 |
| 阅读 | 33.7 → 33.7 | 33.7 → 33.7 |
| 坐下 | 21.0 → 21.2 | 21.0 → 21.3 |
| 躺下 | 52.3 → 37.1 | 52.7 → 39.3 |
| 起身 | 23.4 → 22.5 | 23.5 → 23.9 |

真实动作均有有限粒子坐标，固定点跟踪正常。左袖原始求解代理的结构边最大正伸长分别达到 230.5% 和 224.8%。18 mm 位移上限保护了袖口轮廓，也限制了对原有衣身穿插的修复。坐姿和起身时，部分采样点的结果略差于原蒙皮。阅读、坐卧和快速切换仍需显式分区及针对接触姿势的修形。床垫挤压、腋下内衬、衣身三角面连续碰撞、变形法线和其他硬件上的长时间稳定性均待验收。

## 完整生活舱

生活舱基于 `e6e610b`，使用原有 R3F、灯光、模型与人物更新。对照页面在相同的外套近景挂入开发态帧观察器；开启时只模拟左袖。等待角色出现 120 帧，再预热 4 秒；每个配对窗口采 360 个 rAF 间隔。下表保留两轮原始结果，按实际顺序排列。

| 后端 | FPS | P95 ms | 求解 / 碰撞 / 绑定 ms | 主线程 | JS 堆 / 后备存储 MiB |
|---|---:|---:|---:|---:|---:|
| 关闭 | 94.1 | 16.7 | 0 / 0 / 0 | 100% | 38.1 / 83.5 |
| XPBD | 17.8 | 16.7 | 0.58 / 0.48 / 0.07 | 18% | 53.2 / 86.6 |
| Rapier | 56.2 | 25.1 | 6.69 / 2.41 / 0.14 | 100% | 53.8 / 90.9 |
| Rapier | 75.5 | 25.0 | 3.96 / 1.45 / 0.09 | 100% | 48.8 / 91.5 |
| XPBD | 120.0 | 8.5 | 0.36 / 0.30 / 0.05 | 92% | 72.9 / 87.3 |
| 关闭 | 120.0 | 8.5 | 0 / 0 / 0 | 88% | 59.3 / 83.5 |

第一轮 XPBD 的平均 FPS 明显低于 P95 帧时间所暗示的常见帧率，该窗口存在长尾停顿，成因未定位。窗口内直接计得的求解耗时不足以解释全部差异。Rapier 两轮 P95 均超过 16.7 ms。目前的证据足以保留两条可比较的实验路线，尚不足以通过完整生活舱稳定 60 FPS 的验收。

单独追加的一轮同机复测记录了最长帧间隔。关闭布料为 119.3 FPS、P95 8.5 ms、最长 16.7 ms；XPBD 为 119.7 FPS、P95 8.5 ms、最长 16.7 ms；Rapier 为 98.2 FPS、P95 16.7 ms、最长 16.9 ms。本轮未重现首次 XPBD 停顿。完整三轮的波动与真实袖面残差共同决定暂缓正式接入。

下一批次优先把内外袖、手臂皮肤和衣身分开标记，按弯肘与躺姿校准碰撞体，并把原始蒙皮、校正后袖面与真实衣身的距离放进同一回归。复用同一组代理与动作重测两后端，记录峰值伸长与长帧，再决定生产选型。[实验入口、接口与资产规范](./README.md)
