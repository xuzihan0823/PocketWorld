# 人物模型

当前加载 `luna.glb`，来自用户提供的第二份 `6cb81bde21fa41dfd6b5eb54ed689b2d.glb`。第一份 `d77395cbacc8a6722685cf2d2225500d.glb` 仅用于对比，原始文件保持不变。

新版的卷发、脸部和裙边造型更清楚，站姿更适合基础腿部驱动。两份源文件都是带贴图的单网格，没有骨骼、动画或表情形变。

## 资源预算与处理

- 源文件：77,734,020 bytes，1,497,798 三角形，960,729 顶点，三张 4096 PNG。
- 运行文件：8,255,228 bytes，168,728 三角形，143,588 顶点。
- 源 SHA-256：`73c3b58cc4a43e078bea0ae83170d57e05e08794dc41b1e85dc3ec33c35816be`。
- 运行文件 SHA-256：`e34bb73e7935b9520de767e575eb9226a14fa05b15dd56904bf6780de443a4bb`。
- 使用 glTF Transform 4.2.1、meshoptimizer 0.24.0、Sharp 0.34.2 离线处理；项目运行依赖未增加。
- 烘焙源节点的 X 轴 +90° 旋转，比例 1.2258，身高约 1.45 个场景单位。
- 焊接后以 Meshopt `simplifyWithAttributes` 减面，目标比例 0.055，误差 0.001；法线权重每轴 0.08、UV 权重每轴 0.05。
- 保护正脸顶点：`1.01 < y < 1.32`、`abs(x) < 0.14`、`z > 0.095`，共 66,983 个；受保护约束影响，实际面数高于目标比例。避免仅按位置减面造成鼻口尖角。
- 颜色贴图缩至 2048 JPEG、质量 90；法线贴图缩至 1024 JPEG、质量 92。删除接近常量的金属/粗糙度贴图，改用非金属、粗糙度 0.8；移除强度异常的 specular 扩展。
- 输出为普通 GLB，无需 Draco、Meshopt 或 KTX2 网络解码文件。

## 发色、肤色与脸部精修

依据用户提供的冰蓝长发少女设定图调整嵌入的颜色贴图：头发保留明暗与发丝纹理，减弱偏灰紫感；皮肤适度提暖。使用网格区域与颜色共同筛选，保留眼睛、蝴蝶结、玩偶及衣裙的主要配色。颜色贴图最终按 2048 JPEG、质量 94 导出。

鼻口至下巴的尖锐硬脊在网格上局部修顺：按焊接位置的真实三角形邻接关系平滑，修改 5,548 个顶点，最大位移约 0.0119 场景单位；重算并平滑 5,522 个脸部顶点法线。调整范围为 `abs(x) < 0.07`、`1.18 < y < 1.258`、`z > 0.105`，边缘渐弱。脸外位置、UV、索引、面数及模型坐标尺度保持不变。

随后针对两侧脸颊至下颌的折角，再按连续圆弧局部塑形并作保体积平滑；本轮调整 5,350 个顶点位置，最大位移约 0.00632 场景单位。同步处理 5,544 个局部法线，保护口部并让下巴与两侧曲线衔接。嵌入贴图、材质、UV、三角形索引、文件大小均与上一版一致；正面及左右斜侧面已检查，无新增零面积三角形。

最终材质为非金属、粗糙度 0.88、法线强度 0.35、`KHR_materials_specular` 强度 0.25；共用颜色贴图提供 0.22 的弱自发光补色，以减轻生活舱暖光下的灰黑面部阴影。这是风格化补色，在暗处仍有少量底色，不等同真实皮肤的次表面散射。没有改动房间灯光或曝光，也没有增加运行依赖或贴图张数。

原始 GLB 保持不变；本 PR 交付最终运行模型与处理说明。离线脚本、中间模型和本地检查夹具未提交。

验证：`npm run build`（含 TypeScript 检查）与差异检查通过；GLB 布局与索引合法、数值有限、法线长度正确、无新增零面积三角形；固定中性光下检查正面和斜侧面，生活舱实际渲染检查全身与脸部，加载后九骨骼正常、无页面运行错误。未作实体手机或其他引擎中的美术验收。

## 运行时

`ResidentModel.tsx` 缓存加载资源，为当前实例创建独立几何体与十九根骨骼：原根骨、两腿髋/膝/足、裙前/裙后，增加躯干、颈部和双侧肩/上臂/前臂/手。原主体继续蒙皮，双臂与简化手掌以连续几何连接骨骼，由书柜状态和逆运动学驱动。材质、纹理和原 GLB 文件保留；卸载释放实例几何体、局部重建材质与骨骼纹理。

源网格的静态手臂、玩偶和衣裙存在融合接触面，直接旋转会拉出衣裙长条。书柜任务在运行时分离这些面，重建双臂并封闭服装边界；玩偶沿用原头部、眼罩和耳部特征，补齐原先不可见的背面、躯干与脚，取书前放在柜侧木台，离开时拿回。角色脸、头发与服装主体不替换。局部修复逻辑与验收见 `docs/书柜交互验收.md`。

不包含逐指精细抓握、眨眼/口型、头发或布料物理。模型来源为用户本地提供，未提供额外来源页或许可证，不能归为其他家具资产的 CC0。书柜的触屏检查使用模拟视口，未验收实体手机。
